# Feishu MD Specs (飞书 Markdown 渲染红线)

从 USER.md §3 提取，供 skill 输出时参考。

## ✅ 允许的语法

- 标题 (`#` 至 `######`) — 前后必须有空行
- 独立分割线 (`---`) — 前后必须有空行
- 标准表格 — 用 `|` 分隔
- 带语言高亮的代码块 — ` ```python ` / ` ```bash `
- 行内样式：`**加粗**`, `*斜体*`, `~~删除线~~`, `` `行内代码` ``
- 带协议头的完整链接 — 如 `https://example.com`
- 原生 Unicode Emoji — 直接输出字符，如 🚀

## ❌ 严格禁止

| 语法 | 替代方案 |
|------|---------|
| 外部图片直链 `![](url)` | 飞书专属 `![描述](image_key)` |
| Emoji 短码 `:smile:` | 直接输出 Unicode Emoji |
| 任务列表 `- [ ]` | Unicode 字符 `☐` `✅` `❌` |
| HTML 标签 `<u> <font>` | 飞书原生语法 |
| 扩展语法 `==高亮==` `[^1]` | 不用 |
| 上下标 | 不用 |

## ⚠️ 兜底转义

文本中的孤立 Markdown 特殊字符（如单独出现的 `*` 或 `~`）必须用 HTML 实体转义：

- `*` → `&#42;`
- `~` → `&#126;`
- `[` → `&#91;`
- `` ` `` → `&#96;`

防止飞书渲染树崩溃。
